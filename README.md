# young-parser-kit

QA engineer · Java and Selenium

给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/young-parser-kit.git
cd young-parser-kit
chmod +x run.sh
```
